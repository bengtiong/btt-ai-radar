Hosted model APIs (frontier and open-weight) that remove the need to run your
own GPUs for most workloads.

## Why this ring

The default starting point for building with LLMs — fast to integrate and
operationally simple. Adopt first; self-host only when cost, latency, or data
residency demands it.
