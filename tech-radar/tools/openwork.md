An open-source alternative to Claude Cowork, powered by
[opencode](https://github.com/different-ai/openwork). It brings the
agentic, file-and-task assistant experience into a self-hostable package
so you can run it on your own infrastructure and models.

## What it is

A self-hosted agent workspace: an LLM that can read and edit files, run
tools, and carry out multi-step tasks, packaged as software you host
yourself rather than a managed service.

## Why this ring

Promising for teams that want the Cowork-style workflow without depending on
a hosted product — attractive for data control and cost. It is early and
fast-moving, so Assess it with a proof of concept before relying on it.
